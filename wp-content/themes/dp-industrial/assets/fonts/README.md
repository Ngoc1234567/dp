# Roboto

Primary font: Roboto, normal weights 400, 500, 600, 700, 800. Self-hosted TrueType files fetched from the Google Fonts CSS API, with `font-display: swap` and Arial/sans-serif fallback. License: OFL-Roboto.txt.

Source: https://fonts.googleapis.com/css2?family=Roboto:wght@400;500;600;700;800&display=swap

License source: https://github.com/google/fonts/blob/main/ofl/roboto/OFL.txt

The reference site https://www.phuthaicat.com.vn/vi uses body class `font-main`, whose public CSS resolves to `font-family: var(--font-roboto)`. The reference also loads Inter, but Roboto is its main family. DP uses its own locally hosted Google Fonts files.
